01

设计原则

本页是界面层的唯一权威定义。交互层（流程、信息架构、状态语言）见 docs/DESIGN.md，两者不重叠。

六条硬规则

1
红涨绿跌，不可反转
中国市场惯例，与欧美相反
2
所有数字等宽
金额、数量、涨跌幅、日期一律 tnum，数值列右对齐
3
强调色极度稀缺
靛蓝只给主按钮、导航选中、聚焦环、链接
4
卡片用边框，不用阴影
阴影只给真正脱离文档流的浮层
5
界面文案 100% 中文
代码标识符保留英文但须等宽且只在明细层
6
全部文字通过 WCAG AA
正常文字 4.5:1，大字 3:1，无一例外

配色语义三分法

① 行情色 quote-*
只表达价格与收益的涨跌。以裸文字、图表填充或方向标签底色出现；不用作按钮、卡片、横幅等容器底色。
+3.42%-1.86%0.00%
② 状态色 state-*
只表达系统与任务的健康度。以带底色的胶囊徽标形式出现。
正常注意错误
③ 方向标签 tag-up / tag-down
表达调整方向（加仓／减仓），复用行情色板但以标签形式出现，与状态徽标在形状上区分。
建议加仓建议减仓维持
!
三者不可混用。「综合得分 1.842」「Rank IC 0.0482」「动量 0.182」是统计量而非价格变动，一律用 --ink-900 中性色；它们的好坏由相邻的状态徽标表达，不由颜色表达。同理，覆盖率、达标率这类质量指标不上行情色；「通过／不通过」用状态色 --state-ok / --state-error，不用涨跌色。

状态语义色 — 与行情色严格分离；徽标文字与底色对比度均 ≥4.5:1

#117e56--state-ok4.50:1 AA正常 / 已完成 / 已就绪
#a36100--state-warn4.52:1 AA注意 / 待验证 / 覆盖不足
#c8303c--state-error4.67:1 AA失败 / 异常 / 连接断开
#2a55c8--state-info5.63:1 AA提示 / 说明
#6a5ad2--state-busy4.51:1 AA执行中 / 排队中
#5e6f88--state-idle4.52:1 AA未开始 / 已归档 / 不适用

语义面板描边 — tinted 面板（横幅、判决条、卡点块）的 1px 边；是同名 -bg 的同色相压深

#bfe4d4--state-ok-line—正常面板描边（底色 --state-ok-bg）
#c9daf5--state-info-line—信息面板描边（底色 --state-info-bg）
#f0dcb4--state-warn-line—注意面板描边（底色 --state-warn-bg）
#f2c9cd--state-error-line—错误面板描边（底色 --state-error-bg）
「未开始」读起来是"中性"靠的是没有颜色（相对其余五种的彩色），不是靠低对比度。把灰调浅会掉到 3:1 以下，成为无障碍缺陷。

05

深度与层级

层级优先用表面阶梯与发丝边框表达，而非阴影。阴影只在元素真正脱离文档流时出现。

层级 1 · 发丝分离
1px solid var(--hairline)，无阴影
默认卡片、表格容器、指标磁贴
层级 2 · 内嵌
background: var(--surface-2)，无边框
卡片内的次级块、只读区
层级 3 · 微浮
0 1px 3px rgba(16,39,77,.07), 0 1px 2px rgba(16,39,77,.04)
下拉菜单、气泡、悬浮提示
层级 4 · 浮层
0 12px 32px rgba(16,39,77,.10), 0 2px 8px rgba(16,39,77,.06)
右侧详情抽屉
层级 5 · 模态
0 24px 64px rgba(16,39,77,.14), 0 4px 16px rgba(16,39,77,.07)
命令面板、确认对话框（配 rgba(12,24,46,.42) 遮罩）
阴影一律海军蓝着色，不用纯黑。纯黑阴影在浅灰底上会发脏，海军蓝阴影能让浮层"浮起来"而不是"糊上去"。z-index：内容 0 / 粘性 10 / 下拉 100 / 侧边栏 500 / 抽屉 1000 / 模态 2000 / Toast 2100。
