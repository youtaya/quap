Scope: the current working tree (Alembic `0008`) deployed with `deploy/compose.yaml` + `deploy/compose.local.yaml` on a macOS Apple Silicon host running Docker Desktop (server 29.8.0, `linux/arm64`). ### Upgrade procedure actually executed

1. The previously running stack (image built 2026-09-24, database at Alembic `0003`, no listed instruments or stored quotes) was backed up with `pg_dump --format=custom` to the `local-backups` volume as `pre-upgrade-0003-20260925.dump` before any change.
2. `qc stop` preserved all volumes. The retired `research` container and a stray test PostgreSQL container were removed; the retired role's stale heartbeats were deleted afterwards so `status` no longer lists it.
3. `quant-platform-native:local` was rebuilt; `migrate` ran `0003 → 0004 → 0005 → 0006 → 0007 → 0008` in one transactional pass (39 → 81 public tables).
4. Staged startup: API/dashboard and native workers, then `quant-platform-qlib:local` with the four required engine roles, then the opt-in `research` profile (`qlib-research`, `qlib-diagnostics`, `research-data`) after building `quant-platform-research-data:local`.
